Product / Working prototype

Always watching.
Easy to understand.

Beacon combines a lightweight local device, independent wired and Wi-Fi measurements, event detection, scoring, and multiple user views. The local prototype is functioning today; cloud management and commercial packaging are in development.

Current prototype

Core measurement stack

Latency · jitter · packet loss · DNS · HTTPS · Wi-Fi signal · throughput · AC/battery state · incident mode · quality score

How it works

01 / MEASURE

Continuous local telemetry

Beacon observes wired and wireless paths separately, including min/avg/max latency, jitter, packet loss, DNS and HTTPS timing, Wi-Fi radio data, and power state.

02 / REACT

Incident-mode capture

When an impairment appears, Beacon increases measurement frequency and preserves the event and recovery context instead of waiting for a slow external polling cycle.

03 / INTERPRET

Score and classify

Raw measurements feed Beacon Score and Beacon Grade while fault-domain classification helps distinguish Wi-Fi, local network, upstream/ISP, and power-related problems.

Throughput without becoming the problem

Light probes plus deeper diagnostics.

Current development uses small, frequent throughput probes alongside larger periodic baseline tests and incident-triggered diagnostics. Production bandwidth profiles—including a Low Bandwidth mode—are planned so monitoring does not materially affect the connection being measured.

Local-first architecture

Keep monitoring even when cloud access fails.

Beacon’s local measurement, event, score, API, and dashboard layers are designed to keep operating independently. The planned cloud service will receive outbound telemetry for remote management rather than exposing the device directly to the Internet.

Current development status

Working now: local dual-path monitoring, power/battery telemetry, event capture, incident mode, throughput probes, scoring, multiple dashboard perspectives, and a local API.
Next: probe identity/configuration, outbound cloud upload, remote dashboard, pilot packaging, and production hardening.
